# Security Policy

## Scope

This repository contains documentation and YAML data for the GEO Benchmark Framework. It contains no executable code, services, or user-facing systems. Issues here are limited to:

- Accidentally committed secrets or credentials
- Methodology integrity issues that could enable manipulation of benchmark scores
- Supply-chain concerns (e.g. tampered framework files distributed to consumers)

Vulnerabilities in [AISearchArena.com](https://aisearcharena.com) or related products are out of scope for this repo — please report those through the contact channels on that site.

## Reporting

If you believe you've found a security issue in this repository, please report it privately rather than opening a public issue.

- Email: jamie.watters.mail@gmail.com
- Subject line: `[SECURITY] geo-benchmark-framework`

Please include:
- A description of the issue
- Steps to reproduce or relevant file paths
- Any suggested mitigation

We aim to acknowledge reports within 5 business days.

## Disclosure

Once an issue is resolved, we're happy to credit reporters in the changelog unless they prefer to remain anonymous.
